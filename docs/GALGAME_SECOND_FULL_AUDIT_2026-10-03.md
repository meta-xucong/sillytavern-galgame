
## 优化方向

### HUD

- 保持原聊天为唯一事实源。
- 图片匹配失败不能影响文字记录。
- 明确区分“最近记录”和实时状态。

### Visual

- 保持文本 -> 分析 -> 资源 -> 渲染单向链路。
- 禁止视觉结果反向污染 prompt/context。
- 增加 analyzer 健康诊断和失败原因分类。

### Runtime Bridge

- 只接受原版 Generate 完成后的目标聊天读回。
- 空占位、流式未完成、真正空回复必须区分。
